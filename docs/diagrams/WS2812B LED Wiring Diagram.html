LED MATRIX WIRING GUIDE

5× 8×32 WS2812B · RASPBERRY PI PICO W · 5V 10A · Lincoiah LJH074

STEP 01
PSU → Breakout
Plug barrel jack into breakout adapter
Top screw terminal = 5V (+)
Bottom screw terminal = GND (−)
STEP 02
Bus → Each Panel LEFT connector
Red wire: bus 5V → LEFT pin 1 (VCC) — all 5 panels
White wire: bus GND → LEFT pin 2 (GND) — all 5 panels
LEFT pin 3 = DIN (data only, not power)
STEP 03
Bus → Pico W
Red: bus 5V → Pico VSYS pin 39
White: bus GND → Pico GND pin 38
⚠ Unplug USB when powered via VSYS
STEP 04
Data Chain (Pico → P1 → P2 → ... → P5)
Pico GP28 → 330Ω resistor → Panel 1 LEFT DIN
Panel 1 RIGHT DOUT → Panel 2 LEFT DIN
Repeat P2→P3, P3→P4, P4→P5 using pigtail cables
⚠ RIGHT connector VCC and GND are never connected. Power comes from the bus independently per panel. RIGHT only carries DOUT (data out).
STEPS 01–04
Identical to Schema 1
PSU → breakout, bus → LEFT connector, Pico power, data chain all the same
STEP 05 — NEW
Bus → MID connector (all 5 panels)
Orange: bus 5V → MID pin 1 (VCC)
Teal: bus GND → MID pin 2 (GND)
Wire routes below each panel then up into MID — no data ever
⚠ MID connector = power only. 2 pins: VCC and GND. No data pin exists. Wire drops from bus, travels below panel, rises into MID.
Why injection matters: Without it, power travels the full width of 256 LEDs from the left edge only. PCB trace resistance causes voltage drop — LEDs on right appear dimmer. Injecting at center halves the trace distance and equalizes brightness.
